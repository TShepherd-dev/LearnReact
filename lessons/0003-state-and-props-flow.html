Props flow & lifting state: what replaces $emit

Lessons 01 and 02 covered the component's insides — how markup, state, and lifecycle translate. Now the in-between: how do components talk to each other? In Vue you have props down and $emit up. React keeps the props-down part and replaces the emit-up part with… another prop. By the end of this lesson you'll translate any Vue parent/child handshake into React, and know when state must move up into the parent.

The one idea

Data flows down as props (read-only values). Changes flow up as callback props — the parent passes the child a function, and the child calls it. If two siblings need the same piece of state, that state lives in their closest common parent, which hands each child a value and a callback. This is "lifting state up." (react.dev · Lifting State Up)

In Vue, "the child tells the parent" is an event. In React there is no event system — the parent just gives the child a function and the child reports by calling it.

Read the real files

Open src/components/pagination/pagination.vue and src/components/myTeam/assignment.vue in the source Vue2 repo. They're a classic parent/child pair:

  • Parent (assignment.vue) owns the search state and renders <app-pagination>.
  • Child (pagination.vue) receives start, total, pageSize as props and — when the user clicks next/prev — says this.$emit('onPage', this.currentPage).
  • Parent listens: @onPage="onPage", and its onPage(currentPage) method saves scroll position and pushes the new page number into the route query.
This is literally lifting state: the truth (which page) lives up in the parent (and route), the child is a dumb display control.

Translate it — the child

Vue · pagination.vue (abridged)

props: { start: Number, total: Number, pageSize: Number },
methods: {
  next() {
    if (this.currentPage === this.totalPages) return
    this.currentPage += 1
    this.$emit('onPage', this.currentPage)
  },
  prev() { ... }
}

React · Pagination.tsx

export function Pagination({ start, total, pageSize, onPage }) {
  const next = () => {
    if (currentPage === totalPages) return;
    onPage(currentPage + 1);
  };
  /* ... */
}

Two changes happen at once:

  • Props are function arguments. Vue's props: { start: Number } + this.start becomes destructuring the first parameter: { start, total, pageSize, onPage }. No this.
  • $emit('onPage', page) becomes a call: onPage(page). The event name is now a prop the parent named. The child doesn't broadcast — it calls the function it was handed.

Translate it — the parent

Vue · assignment.vue (abridged)

<app-pagination
  v-if="assignableTeamMembersTotal"
  :start="searchOptions.pn"
  :total="assignableTeamMembersTotal"
  @onPage="onPage"
  :pageSize="searchOptions.nr" />

methods: {
  onPage(currentPage) {
    routerUtility.saveScrollPosition()
    this.searchOptions.pn = currentPage
    this.$router.push({ query: { pn: currentPage } })
  }
}

React · Assignment.tsx

const [pn, setPn] = useState(0);

return (
  {assignableTeamMembersTotal > 0 && (
    <Pagination
      start={pn}
      total={assignableTeamMembersTotal}
      pageSize={searchOptions.nr}
      onPage={(currentPage) => {
        setPn(currentPage);   // update the lifted state
        navigate(`?pn=${currentPage}`);
      }}
    />
  )}
);

Note what stays the same:

  • The grammar is identical: :start="x" @onPage="h" → start={x} onPage={h}. Both directions are just props.
  • v-if from Lesson 01 — now as {cond && ...}. You're using the previous translations naturally.

And the one thing that's now explicit: the page number lives in the parent. The routed query string and React state agree, and the child only reports clicks. State is lifted.

Why this matters for your mission

The source app is full of handshake pairs like this — videoPlayer emits videoEnded, liveSearch emits input, memberOptions emits revoke-access & friends. Every one of them is a prop callback in React. More importantly, Vue 2's relaxed $emit lets parents and children drift; React forces the question "who owns this value?" into the open. Your port repeats these 15 symbols a hundred times — make them reflex.
